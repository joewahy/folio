# Eval corpus sources

Four documents, chosen for structural variety (see `evals/corpus.py` for
the rationale and the 40 questions). Two are generated from text held in
this repo; two contain real third-party text.

| File | Origin | License / status |
|---|---|---|
| `notes_primer.pdf` | Generated by `build_corpus.py` from prose written for this repo | Original, this project |
| `thermostat_manual.pdf` | Generated by `build_corpus.py`; describes a fictional device ("Aurora T-200"), any resemblance to a real product is coincidental | Original, this project |
| `apache_license_2.0.txt` / `.pdf` | Verbatim text of the Apache License, Version 2.0, fetched from <https://www.apache.org/licenses/LICENSE-2.0.txt>. The `.pdf` is that same text typeset by `build_corpus.py`. | The license text may be reproduced verbatim (it is itself a license grant); it is included here only as a sample document to run retrieval against, not as the license of this project. |
| `nist_sp800-63-3.pdf` | NIST Special Publication 800-63-3, *Digital Identity Guidelines* (June 2017, with updates through 2020). Downloaded as-is from <https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-63-3.pdf>. | U.S. government work — not subject to copyright in the United States (see the publication's own statement, "not subject to copyright"). NIST has since withdrawn/archived this revision; it is used here purely as a fixed, real-world test document. |

## Regenerating

```bash
python evals/corpus/build_corpus.py
```

regenerates `notes_primer.pdf`, `thermostat_manual.pdf`, and
`apache_license_2.0.pdf` deterministically from the text in this
directory. `nist_sp800-63-3.pdf` is committed as downloaded and is not
regenerated; to refresh it, re-download from the URL above.
